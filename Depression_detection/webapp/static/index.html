Architecture Insights: LightGBM Ensemble

Our ensemble approach leverages Gradient Boosting to capture non-linear relationships between vocal harmonics, facial action units, and linguistic despair markers. The combination of multimodal features reduces the Mean Absolute Error significantly compared to unimodal baselines.

  • MAE: Represents the average error in PHQ-8 score points. Currently ±4.93.
  • R² Score: Indicates the percentage of variance explained by features.
  • Fusion: Weighted late-fusion of modality regressors.

Dataset & Technical Architecture

The system is built on 189 patient recordings from the AVEC-2017 depression dataset, leveraging 189 participant recordings across three core modalities:

TEXT (BERT)

State-of-the-art transformer contextual embeddings capture semantic despair indicators.

AUDIO (MFCC)

Acoustic delta and spectral features analyzing vocal flattening and speech prosody.

VISION (OPENFACE/CLNF)

Facial Action Units and landmark features extracted with the same CLNF representation used during training.
